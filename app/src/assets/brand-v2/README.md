# Frank brand v2 candidate

This directory contains the active Frank brand sources, platform-ready raster exports, and project-submission assets.

## Concept

The mark is an abstract `F` assembled from a root stem and two conversation lanes. The violet lane represents encrypted communication; the mint lane represents value moving through the same identity.

## Palette

- Violet: `#9D5CFF`
- Mint: `#00D9A3`
- Ink: `#121218`
- Light surface: `#F7F7FB`

## Files

- `frank-mark.svg`: transparent two-color master mark
- `frank-mark-mono.svg`: one-color mark using `currentColor`
- `frank-app-icon.svg`: dark rounded-square launcher icon
- `frank-adaptive-foreground.svg`: safe-zone artwork for Android adaptive icons
- `frank-lockup.svg`: horizontal mark and wordmark
- `icons/`: 24px outline icons for message, identity, payment stamp, and atomic swap
- `raster/`: rendered PNG previews and submission/app-icon sizes

Use the standalone mark where the name is adjacent. Use the lockup for headers and project pages. Use the monochrome mark below 24px when maximum clarity is needed.
