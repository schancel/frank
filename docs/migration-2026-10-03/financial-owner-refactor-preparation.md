Re-open and finalization must reconstruct/revalidate from existing durable facts exactly where the current code does so; do not introduce extra live chain polls or elevate component checks to new finality assurance.

The HTTP wrapper translates financial errors one-to-one into existing `ProcessMonadMessageError` variants and details. Private module RPC primitives use the existing JsonRpcTransport/MonadHttpClient and existing timing config; only the current outbox owner controls when a replay is charged/persisted and invokes them.
