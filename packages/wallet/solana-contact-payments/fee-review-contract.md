# Experimental unsigned Solana financial review

This Tier 3 predecessor replaces caller-invented fee ceilings with actual unsigned financial review. The existing SolanaPaymentState remains the sole operation/inventory/reservation/incoming owner. Custody retains derivation and signing. The separately authored public fixed constructor owns no seed or signature authority; canonical injected RPC owns observations, not inventory credit.

Format 4 deliberately rejects prior experimental snapshots. No migration, reset, defaults for old records, compatibility quote alias, key deletion, protocol allocation or app activation is authorized. The existing operations map gains a quoting variant, rather than a competing draft owner/map. Core intent, planned sources/amounts and random contexts persist before destination derivation. Final quoted operations are committed atomically and are the only values returned to review UI.

quoteReview accepts operationId, canonical chainIdentifier, recipientSpendPoint, asset, amount and explicit destination-ATA creation permission. It accepts no fee budget or recipient-native-gas subsidy. Fixed fee-probe messages are estimation only. Exact final unsigned messages are queried before approving each member fee/rent/native-debit ceiling and their exact aggregate sums. Per-member authorizations replace global per-transfer ceiling multiplication. All atomic quantities use exact bigint and canonical u64 strings.

Final source proposals are immutable and unreserved. Prepare claims those exact currently available sources atomically, rechecks current fee/rent with an exact unsigned message before signing and rejects changed financial requirements. Fresh blockhashes are permitted before signing only within the same approved operation/contexts/asset/recipient/amount/sources/caps. Review blockhash evidence has an explicit last-valid height and does not promise indefinite transaction validity. After complete signed originals persist, retries/reopen/reconciliation use only those bytes. No expiry-based replacement or claim reset occurs.

Acceptance: unsigned quote never signs/reserves/exposes; actual native/classic-SPL fees and optional ATA rent are displayed distinctly; persisted contexts survive interrupted derivation and reopen; repeated IDs are immutable; exact member/totals bind approved fees; source conflict and fee/rent rise reject before signing; public unsigned messages equal actual WASM signed messages; received multisource import/reopen/respend and original-only exposure/recovery remain covered. Incoming format guards and strict IndexedDB browser tests update faithfully to format 4. Independent review remains required before integration/activation.

The implementation baseline is combined `5672d3adb13c680fd1178cac489a3bbe2c648980`, selection predecessor `26e7b8868fef1a880700a9a302f54d035d042f98` transported alone, and public unsigned constructor predecessor `3de76bb6eade2223d827fc2f20b63b587988bd98` transported alone. The owner imports its standalone public functions through a separate `experimentalSolanaPaymentConstruction(wasm)` adapter; existing custody handle exports remain unchanged.

Construction uses a public representative destination for planning only. Exact final-message fee mismatch leaves a visible incomplete retained draft rather than an approved review; the current bounded implementation does not assume fee invariance or invent an iterative larger budget. The actual closed signer message must equal the freshly checked public message byte-for-byte.
