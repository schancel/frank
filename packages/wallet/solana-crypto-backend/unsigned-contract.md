# Public unsigned construction prerequisite

Tier 3, based on `5672d3adb13c680fd1178cac489a3bbe2c648980`. The financial owner needs an actual fixed message for RPC fee observation before approval. Signing to discover the fee would cross the approval boundary. This predecessor adds public construction only; it installs no adapter and changes no state, persistent format, scheme allocation, key derivation, rent policy, or application flow.

The Rust transfer builder remains the sole owner of fixed native/classic SPL/explicit idempotent ATA instruction construction. The existing custody signer retains private deterministic R/P recomputation, primary or received source ownership proof, lifetime checks and signature generation. Public construction cannot attest seed ownership, ECDH derivation, truthful RPC quotations, balances, or settlement.

Agreed runtime API with the financial owner:

- `unsignedTransferMessage({descriptor,spend,authorization,source}, wasm): Promise<Uint8Array>`, where source is exactly `{kind:'primary'}` or `{kind:'received',received:PublicDestination}`. It validates canonical chain, public points, complete descriptor/spend tuple, positive amount, classic asset, fee/rent/debit caps and received source/Q binding. For valid inputs its unsigned message is byte-identical to the existing signer's message. It accepts no instruction, seed, scalar, arbitrary message or signature input.
- `feeProbeMessage({domain:'frank:solana-custody-fee-probe:v1',chainIdentifier,asset,owner,destination,amount,recentBlockhash,decimals,createDestinationAta}, wasm): Promise<Uint8Array>`. It constructs only the same fixed transfer/ATA instruction forms with an explicit estimation memo. Destination must be a valid point; a representative destination makes this an estimate only. The probe has no authorization or cryptographic descriptor semantics and never substitutes for the final message. The financial owner must persist contexts, derive exact destinations and query `unsignedTransferMessage` bytes before final immutable approval caps; equal sizes do not prove fee invariance.

Both functions load the committed WASM package without opening custody or retaining keys. The input source union is closed, unknown JSON fields reject, and outputs contain message bytes only. Private signing must not be weakened to accept a probe or skip its derivation/source proof. Existing frozen Q/J/signature formulae and memo bytes for actual signing remain unchanged.

Allowed scope is this backend's Rust, bindings, runtime declarations, generated artifacts and co-located tests/docs. No session, state, engine, app, RPC, wire or fee-policy edits. Proof includes Rust public/private message equivalence and rejection, actual Chrome WASM native/SPL/ATA/received equivalence and unchanged signature checks, no-custody package construction, pinned generator/source equivalence, existing vectors and configured typechecks. A separate reviewer examines the frozen commit; tests are not a formal external audit or production approval. Rollback removes these public exports and regenerates the package, with no migration.
